# Simstrate

**Simstrat(e) — Simulation et stratégie de l'entreprise**, Éditions Labodidact.

Jeu de simulation de gestion à usage pédagogique pour Windows 3.x, écrit en
Delphi 1 avec des données Paradox. Jusqu'à 8 équipes se concurrencent sur un
marché commun ; à chaque période, un animateur arbitre et le logiciel produit
les états financiers de chacun.

L'éditeur a cessé son activité et le logiciel n'est plus distribué. Ce dépôt
conserve ce qui subsiste et reconstitue son fonctionnement.

## Contenu du dépôt

- `Simstrat (FR)/` — version de démonstration 1.21, son fichier d'aide et
  six jeux d'exemple complets
- `Simstrate.zip` — la même distribution, telle que diffusée
- `analyse_decompilation/` — analyse, documentation reconstituée, captures
  d'écran du logiciel en fonctionnement, et les outils écrits pour y parvenir

## Avertissement

La version incluse ici est une **démonstration** : elle ne permet ni de créer
un jeu, ni de saisir des décisions, ni d'arbitrer. Elle sert uniquement à
consulter les jeux d'exemple. Elle n'est pas utilisable en formation.

Le logiciel reste protégé par le droit d'auteur. Ce dépôt a une finalité de
conservation et d'étude.
